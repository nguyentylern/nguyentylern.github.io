This website is a fictional foodbank website created for FCS Innovation Academy's project week. It is a minimalistic website that allows users to search for nearby foodbanks based on their ZIP code. It is built using HTML, CSS, and JavaScript, and it utilizes the Google Maps API to display nearby foodbanks. The website is no longer functional.
