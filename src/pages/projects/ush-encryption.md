This is a website made for my U.S. History class explaining the history of encryption during WWI. It features an implementation of the Playfair cipher and also the Advanced Encryption Standard (AES). Users can encrypt and decrypt messages using these algorithms.

[You can view the website here](https://nguyentylern.github.io/ush-encryption).
